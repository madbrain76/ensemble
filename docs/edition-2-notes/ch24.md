## Corrections for the later author/coder phase

- §24.3: the statement that a struct literal enforces every field's presence is
  incorrect for keyed Go literals, which may omit fields. Construction alone
  does not establish required-parent validity.
- §24.6: an external consumer cannot directly import `internal/llm` to name a
  missing public type. Public API usability must be checked from outside.
- §§24.1/24.5: `go list -deps` establishes import reachability. Avoid claiming
  that every line of each dependency necessarily survives in the linked binary.

Preserve the chapter's useful account of finding the second WebSocket dependency
and inaccessible event types; those examples explain why the boundary checks
matter. Future revisions should reconcile that story with the restart's actual
implementation after the student succeeds.
