## Keep the original persistence exercise small

The assignment is the four-field JSON save (`config`, `as_of`, `context`, `log`),
default load/start and save/exit, and the existing reducer's snapshot-plus-tail
restore. Runtime configuration wins; credential/base-URL secrets do not enter
the save. Continue sequence numbering after both the anchor and loaded log.
Reject an unreadable/invalid existing save without overwriting it. The public
`--save PATH` changes the same path in both directions, never enables loading.

Determinism means byte-identical **next vendor requests** from a full save versus
its full log replay. It does not require a new canonical JSON disk format, hashes,
origin certificates or an integrity framework. A deliberately older snapshot
with a newer tail must apply that tail exactly once. A snapshot with no log is
valid; deleting that snapshot too is not a replay-equivalence case. Reuse the
existing context and reducer instead of inventing a second state model.

The chapter explicitly leaves indentation and replacement writes to the student;
its optional `verify` command is outside grading. Do not treat that reference
convenience as required. Journal/crash-recovery machinery belongs to the later
chapter, as the carryover already states. The first attempt's oversized save/load
implementation remains a failure to avoid, not an answer or feature inventory.

Original text locates the default file beside settings in the working directory.
Bill's carryover requires paths to belong to the owning Agent under the
application-selected data directory. Preserve that ownership when applying the
exercise's path contract; if the actual launch convention conflicts, document
and resolve the concrete conflict under the existing review procedure rather
than silently introducing global state or a migration framework.

The live exercise is a short two-process remembered-word conversation, plus the
stated log-only/snapshot-only restoration and corrupt-file refusal. Use small,
sanitized artifacts and the existing credential procedure. Do not turn it into
an expensive provider/format matrix or claim fake-provider success is live use.
