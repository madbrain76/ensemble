## Binding scope reminders

Bill's architecture overrides the common-package gate implementation and flat
construction sketches. Shared interfaces/data belong in common; behavior belongs
with its owner. GUI/WebSocket implementation stays in its separate optional
module and consumes public core interfaces. The real CLI and browser share one
Agent through that public seam. Introduce only Chapter 8's artifacts, transport,
replay, voice and pause; no Chapter 9 workbench or forthcoming sub-agents.

Pause is Agent-wide. An explicit unpause in any tab unpauses the Agent for every
tab. Local speech/typing transitions do not create independent tab vetoes.
Interrupt ends the current turn, keeps the Agent usable and preserves other jobs'
real results. The gate must not make interruption depend on first unpausing.

as the carryover explains. Reconnect must preserve completed content and active
partials. Existing synchronized history access remains necessary: append-only
data alone does not make concurrent slice access safe. Do not implement the
later save/load chapter to satisfy this chapter's loose restart wording.

availability safely. Chapter 7 initially used 2.5 Flash because the handoff and
review missed his restriction; do not repeat that selection mistake. If the
