## 2026-08-07 — cardsense-go: cross-display detection fixed (laptop panel)

Bill reported a "crash" and total detection failure on his MacBook panel (1470×956)
after calibrating on a 4K external. Two commits: `6d7cb9b`, `5b894f3`.

### Root causes (four, not the one we started with)

1. **RefBox geometry was wrong on EVERY display.** (21,47,449,709) @1920×1080 = aspect
   0.633, but a Magic card is 63×88mm = **0.716**. The box was ~80px too tall. This is
   why the 4K run ALSO floored at dist≈188 — I initially misread that as a separate
   laptop-only problem. Replaced with a pixel-measured box: **(13,100,396,556) @1470×956**,
   aspect 0.712. Cross-check that confirmed it: scaling the new box up to 1920×1080 gives
   width 447 vs the old 449 — the old WIDTH was right, only the height was wrong, which is
   exactly why the bug hid for months.

2. **Non-uniform scaling.** `LoadCalibration` scaled X and Y by independent factors,
   squashing the crop to aspect 0.537 on a 16:9 → 16:10 move. Now `scaleBox()` uses a
   uniform `min()` scale about the screen center. This also matches how MTGA scales its
   preview: **with window HEIGHT**.

3. **Twiddle couldn't escape.** Steps were only 1% and 0.1%; from a bad box it moved
   exactly ONE pixel and stayed pinned at 188. Now coarse-to-fine: 8%, 3%, 1%, 0.1%.

4. **Calibration saved garbage.** Trigger was `minDist < 200` (accepts everything) and the
   save was unconditional. It would calibrate on an empty board, twiddle to 190, and
   persist that — overwriting a good dist=54 box. Since calibration persists and becomes
   the scaling source for later runs, ONE bad frame poisoned all future sessions. Now
   triggers <150 and only accepts/persists if twiddle converged <100.

### Measured populations (the key diagnostic numbers — reuse these)
- real card: **dist 60-90, margin 84+**
- empty board / UI: **dist 190-202, margin 0-6**
- 150 sits in the empty gap. Both the calibration trigger and OCR Guard 1 had been set to
  200, i.e. INSIDE the noise cluster.

### The "crash" was me
`(./cardsense-gui > log 2>&1 &)` inside a `run_command` job dies when the job is reaped —
no crash report, no panic, log just stops. Bill spent minutes hovering cards at a dead
process. **Use `nohup ./cardsense-gui > /tmp/x.log 2>&1 & disown`** — survives fine (5+ min
verified). Check `ps -A | grep cardsense-gui` before trusting an empty log.

### OCR false positives (dangerous, partially fixed)
Tesseract read garbage `'Wg ZAM'` off a board view; Scryfall's **fuzzy** search resolved it
to a real card, *'Merrow Grimeblotter'*. Also `'Wise'` repeatedly. For an accessibility
tool, confidently speaking a WRONG card name is worse than silence — the user cannot know
it's wrong. Tightened Guard 1 to 150. Guard 1b (`margin < 1`) is still far too permissive
given real cards show margin 84; consider raising to ~20. OCR title extraction is also
weak: it produced `'Wi ae fo'` from a clean, unclipped card.

### Method lesson (the one that actually mattered)
I spent several rounds reasoning about aspect-ratio arithmetic. What broke it open was
**cropping the box with the screenshot tool and LOOKING at it** — the clipped mana symbol
made it obvious in one glance. Also: `dist≈198 with margin≈0` means "this isn't a card at
all" (every index entry equally bad); a near-miss shows high distance WITH a real margin.
I read the first as the second initially.

I also raised a false alarm: flagged `[WARNING] ids.npy parsing not fully implemented` as a
possible cause of wrong names. It's harmless — `Meta`/`Names` come from `phash_meta.json`
positionally and the placeholder IDs are never used for naming. I should have read the
loader before warning Bill.

### Build command (macOS)
```
cd ~/projects/cardsense-go
export PKG_CONFIG_PATH="$(brew --prefix opencv@4)/lib/pkgconfig"
go build -o cardsense-gui ./cmd/gui
```
Must be `opencv@4` — Homebrew's plain `opencv` is v5 and ships `opencv5.pc`; gocv v0.43
needs `opencv4.pc`. NSSpeechSynthesizer deprecation warnings are expected noise.
Calibration file: `~/projects/cardsense/hashindex/data/calibration.json` (delete to reset).
