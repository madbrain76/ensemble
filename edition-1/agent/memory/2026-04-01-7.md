### Bugs Found and Fixed
1. **Safe mode tool leak**: GetCustomTools() returned ALL built-in tools from registry, bypassing safe mode. Fix: BuiltIn flag + GetCustomDefinitions() skips them.
2. **env.sh export keyword**: systemd EnvironmentFile doesn't support `export`. Stripped it.
3. **API key not loading**: Two causes: (a) ProxyViaCodeRhapsody defaults true, uses empty proxy key. (b) ResetConversationHistory=true skips LoadSettingsFromDisk(). Fixed both.
4. **Double data/data directory**: Relative project_path "./data" breaks after server CWD change. Fixed with absolute paths in config.json.
