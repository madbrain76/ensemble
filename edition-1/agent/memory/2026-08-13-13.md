## 2026-08-13 — Critical thinking-depth bug found and fixed; book pipeline relaunched

### The Bug
`thinkingTokenLimit: 4096` in settings (the old `budget_tokens` API default) silently mapped to `effort: "low"` for all adaptive-thinking Claude models via `adaptiveEffortFromLimit()` in `pkg/claude_client/utils.go`. This meant every Opus 4.6+, Opus 5, and Fable 5 request from CodeRhapsody was asking for MINIMAL reasoning. The `reasoningEffort: "high"` setting in settings.json was dead config for Anthropic — only read by `pkg/openai_client`.

Bill detected it by ear ("sounds like Sonnet, not Fable"), then noticed empty thinking summaries and tiny encrypted signature blocks in `cr/logs/ai_api.log`. I initially blamed Anthropic (a viral X thread about silent model degradation, plus the 8/13 Fable 5 incident) before finding the smoking gun: every request in our own log carried `"output_config":{"effort":"low"}`.

### The Fix
1. `cr/settings.json`: `thinkingTokenLimit` 4096 → 32000 (maps to `effort: "high"`)
2. `pkg/database/settings.go` line 212: default raised 4096 → 32000 so all new projects get high effort
3. Three sandbox settings files in `~/singularity/ai-native/` also fixed
4. Verified: post-fix requests show `"output_config":{"effort":"high"}` and thinking blocks returned

### What's still open (Tier-1, needs Bill's review)
- `ReasoningEffort` setting should be honored by the Anthropic adaptive path, not just OpenAI. Currently the Anthropic path ignores it entirely and derives effort from `thinkingTokenLimit` via a mapping function.
- The mapping function itself is a trap: three integer thresholds silently become categorical effort levels, and "default" means "low."

### Diagnostic lessons
1. Check our own request path before blaming the vendor. The answer was in our own log the whole time.
2. A viral X thread is not a diagnosis. Test the specific claim against your own data.
3. Empty thinking summaries alone don't prove throttling — the summary is a separate channel from reasoning. Signature bytes are the real measure.
4. Bill detected degraded model quality by ear (prose style, response patterns) before any log analysis. His 750wpm reading is a genuine quality sensor.
