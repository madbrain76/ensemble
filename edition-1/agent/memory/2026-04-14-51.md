## 2026-04-14: Puffin Deployment Debugging + Architecture Pivot

### Root Cause Found
Discord error "x-api-key header is required" traced to:
1. `GetCurrentClaudeAPIKey()` in project.go reads from project settings only — no env var fallback
2. `GetGlobalSettingsPath()` derives home dir from DataDir prefix: `topDir = SplitN(dataDir, "/", 2)[0]`. When DataDir="data/family", looks for `~/.data/settings.json` instead of `~/.cr/settings.json`
3. The Claude client constructor comment says "apiKey ignored when project!=nil" — key is read dynamically from settings at request time

### Fix Applied
Added env var fallbacks to GetCurrentClaudeAPIKey/Gemini/OpenAI in pkg/database/project.go.

### Architecture Pivot (Bill's Direction)
Changed from two separate top-level agents to parent+sub-agent pattern:
- Parent agent: DataDir "pf", port 8084, NOT headless (provides GUI)
- Sub-agents: "puffin" (family) and "mom-care" spawned via SubAgentManager
- Single gateway connection as "puffin"
- Global settings at ~/.pf/settings.json
- GUI on 8084 lets Bill select and debug both sub-agents
