## 2026-07-27 — cardsense Go Port: OCR Fallback Not Enabled in GUI

**Problem**: Scathe Zombies failing to be identified in the GUI, but tests showed both Python and Go OCR working correctly.

**Root Cause**: OCR fallback was **disabled** in the detector loop
- Line 193 in `pkg/detector/detector.go`:
  ```go
  hit := d.idx.Identify(cropGray, true, 280, 20, nil, false)  // ❌ false
  ```
- The `ocrFallback` parameter was hardcoded to `false`

**Verification**:
- Python standalone test: ✅ Scathe Zombies identified (OCR: "ScatheZombies a Qe")
- Go standalone test: ✅ Scathe Zombies identified (OCR: "Scathe Zombies a Qe")
- GUI: ❌ Failed because OCR was disabled

**The Fix**:
Changed detector to enable OCR fallback:
```go
hit := d.idx.Identify(cropGray, true, 280, 20, nil, true)  // ✅ true
```

**Files Modified**:
- `cardsense-go/pkg/detector/detector.go` (line 194)

**Status**: GUI rebuilt with OCR fallback enabled. Should now identify both Octoprophet and Scathe Zombies correctly.

**Lesson**: When porting code, check that feature flags and parameters match between Python and Go. The OCR fallback infrastructure was fully ported but left disabled in the production code path.
