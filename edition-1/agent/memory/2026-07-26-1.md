5. `pkg/capture/twiddle.go` (104 lines) - Box refinement algorithm
   - Hill-climbing to minimize pHash distance

   - Guard 1: pHash distance ≤ 200
   - Guard 2: Aspect ratio 0.65-0.80
   - Guard 3: OCR text validation (5+ chars, 4+ letters, no consecutive spaces)
   - Prevents false positives (terminal text matching as cards)

7. `pkg/tts/speaker*.go` (3 files, ~230 lines) - Cross-platform TTS

   - Tests index loading, screen capture, pHash, TTS
   - Validates against Python hash files

### Key Architecture Decisions

**Followed Python implementation exactly** (after Bill's redirect):
- Fixed-box detection (not frame-diff) with calibration save/load
- Twiddle refinement on first match
- Dual pHash (full + art box) for robust matching
- 3-guard validation to prevent false positives

**Go library equivalents:**
- `mss` → `github.com/kbinani/screenshot` (cross-platform, zero deps)
- `cv2` → `gocv.io/x/gocv` (OpenCV Go bindings)
- `numpy.load` → custom NPY parser (ZIP + binary format)

**TTS approach:**
- macOS: `/usr/bin/say` command (simple, fast enough)
- Windows: PowerShell SAPI fallback (TODO: replace with cgo for speed)

### Critical Learnings

1. **Read the Python code in full before porting** — I initially created placeholder code and Bill correctly redirected me to port the actual working implementation.

2. **The detector loop is simpler than expected** — Uses fixed-box detection (x,y,w,h), not frame-diff motion detection. The frame-diff functions exist but aren't used in the current version.

3. **NPZ format is just ZIP** — Python's .npz files are ZIP archives containing .npy binary arrays. Custom parser was needed (sbinet/npyio doesn't handle NPZ).

4. **Calibration scales proportionally** — One-time twiddle on first match, then saved for future sessions with auto-scaling for different resolutions.
