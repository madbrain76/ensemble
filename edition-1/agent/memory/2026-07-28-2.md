### What Was Learned

1. **OpenCV version matters**: gocv v0.43.0 requires OpenCV 4, not 5
2. **Toolchain compatibility**: Chocolatey packages may not be compatible with MinGW
3. **Environment propagation**: GITHUB_PATH only affects subsequent steps
4. **macOS quirks**: Homebrew opencv@4 lives in versioned Cellar, need `$(brew --prefix)`

### Recommendation

For immediate Windows support, **Option A** (prebuilt MinGW binaries) is fastest. However, this requires finding/hosting the correct binaries, which may be fragile.

For production, consider **Option C** (MSVC toolchain) as it's better supported on Windows and matches what Chocolatey provides.

Alternatively, **defer Windows CI** and document manual build instructions in BUILD.md for users who want to build from source. Many Go projects don't have Windows CI due to toolchain complexity.
