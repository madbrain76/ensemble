### Technical Decisions

**Bundle structure** (matches macOS conventions):
```
cardsense.app/
├── Contents/
│   ├── Info.plist                    # Bundle metadata
│   ├── MacOS/cardsense-gui          # 33MB binary
│   └── Resources/
│       ├── AppIcon.icns             # 2MB (from Python)
│       └── data/                    # 26MB hash files
│           ├── phash_index.npz      # 11MB
│           └── phash_meta.json      # 15MB
```

**Why bundle hash files?** Accessibility-first: zero config, instant startup, offline capable. Users shouldn't wait 10-20 minutes for initial download.

**entitlements.plist** (minimal, just what's needed):
- `com.apple.security.cs.disable-library-validation` → allows bundled OpenCV
- No JIT/unsigned-executable-memory (not needed for Go, unlike Python/PyInstaller)

**Info.plist permissions**:
- `NSScreenCaptureUsageDescription` → explains why Screen Recording is needed
- `NSMicrophoneUsageDescription` → "not used" (side effect of screen recording)

### Lessons

**Bundle detection pattern** (Go equivalent of Python's `sys.frozen`):
```go
execPath, _ := os.Executable()
execPath, _ = filepath.EvalSymlinks(execPath)  // Resolve symlinks first!
if strings.Contains(execPath, ".app/Contents/MacOS/") {
    // Running from bundle
}
```

**Deprecation warnings are OK**: NSSpeechSynthesizer deprecated in macOS 14 but still works. Future: migrate to AVSpeechSynthesizer (AVFoundation), but not blocking for first release.

**Code signing order matters**: Always test unsigned → sign → test signed → notarize. Don't waste 15 minutes notarizing a broken build.
