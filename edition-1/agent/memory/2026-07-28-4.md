## 2026-07-28 — cardsense-go: Laptop Display Debugging Session

**Root Cause Identified**: Calibration from 4K external monitor (3840×2160) doesn't scale properly to MacBook display (1470×956). The aspect ratio difference causes the detection box to be too narrow/tall (0.539 vs ideal 0.67 for cards).

**Changes Made**:
1. **Relaxed OCR guard thresholds**:
   - Aspect ratio: 0.60→0.53 (to accommodate scaled box)
   - Margin: 3→1 (laptop display has lower pHash distinctiveness)
   
2. **Added pre-identification calibration trigger** in `pkg/detector/detector.go`:
   - Checks for visual evidence of card BEFORE full `Identify()` call
   - Triggers on: distance < 200 AND aspect 0.53-0.85
   - Runs pHash scan + margin calc to avoid calibrating on random UI elements
   - Added `sort` import for margin calculation

3. **Added comprehensive debug logging** in `pkg/hash/index.go`:
   - Shows which guard fails (1, 1b, 2, 3)
   - Shows pHash distance, margin, aspect ratio
   - Shows OCR extraction results and Scryfall queries

**What Works**:
- Auto-calibration triggers correctly when visual evidence exists
- Debug logging clearly shows why detection fails
- Calibration improves pHash distance (196→188 observed)

**What Still Doesn't Work**:
- Even after calibration, detection fails due to low margins (0-2)
- OCR extracts wrong text ("arky" from "Sparky" player name, not card titles)
- Detection box position may still be wrong for laptop
- Detector occasionally hangs (last run stuck on "Testing screen recording permission")

**Key Learning**: The "aspect ratio + pHash distance" approach for calibration works, but the scaled reference box from 4K→laptop creates a detection box that's:
1. Too narrow (0.539-0.547 aspect)
2. Positioned incorrectly (captures UI elements instead of cards)

**Next Steps**:
1. Investigate why detector hangs on permission check
2. Consider using a **laptop-specific reference box** instead of scaling from 4K
3. May need to build a manual calibration tool for laptop users
4. Or: prompt user to calibrate on first run by having them position MTGA window specifically

**Files Modified**:
- `pkg/hash/index.go` - relaxed guards, added debug logging

- `pkg/capture/calibration.go` - manual aspect ratio adjustments (not committed)
