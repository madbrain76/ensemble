### GitHub Actions Workflow Created

**File**: `.github/workflows/build.yml`

**Jobs**:
- `build-macos`: Builds on macos-latest
- `build-windows`: Builds on windows-latest  
- `release`: Uploads artifacts to GitHub releases (on release events)

**Key lessons learned**:

1. **macOS**: 
   - OpenCV 5.0.0 provides `opencv5.pc`, but gocv v0.43.0 requires OpenCV 4.x (`opencv4.pc`)
   - Solution: Install `opencv@4` instead of `opencv`
   - Must set `PKG_CONFIG_PATH="$(brew --prefix opencv@4)/lib/pkgconfig"`
   - Must suppress NSSpeechSynthesizer deprecation warnings with `-Wno-deprecated-declarations`

2. **Windows**:
   - MinGW installs to `C:\ProgramData\mingw64\mingw64\bin` (not the Chocolatey lib path)
   - `GITHUB_PATH` changes only take effect in NEXT step, not current step
   - Solution: Directly set `$env:PATH` in PowerShell build script
   - Must set `CGO_ENABLED=1`, `CGO_CPPFLAGS`, and `CGO_LDFLAGS`

3. **Dependencies**:
   - macOS: `brew install opencv@4 tesseract`
   - Windows: `choco install mingw opencv tesseract`
   - Order matters on Windows: MinGW → OpenCV → Tesseract
