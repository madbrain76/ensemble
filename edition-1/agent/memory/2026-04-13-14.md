### Architecture Decisions
- **Three channels, one brain**: Voice PE (ambient), Twilio (phone), Discord (caregiver text)
- **Home Assistant Voice Preview Edition** ($59) as the ambient voice device, connected to Pi 5 running HA
- **webhook-conversation** HA integration sends text to Puffin REST endpoint — we never handle raw audio
- **Twilio ConversationRelay** for phone calls — both direct (Puffin calls mom) and conference (family calls)
- **Cloud STT/TTS** (not local) — accuracy matters more than latency for elderly speech
- **Puffin's Memory** — structured knowledge base about mom (people, medications, appointments, routine). JSON on xyzzy. Fed by all channels.
- **Escalation chain**: Voice PE → cell → landline → Bill (Discord) → Bill (phone) → friend
- **Speaker ID**: Twilio conference identifies speakers by phone number

### Key Rejected Approaches
- Discord voice as mom's speakerphone (Wyoming protocol is pipeline-specific)
- Local Whisper on Pi (7.7% WER, worse for elderly speech; cloud is dramatically better)
- Alexa (session timeouts, middleman, cognitive load)
- Custom Pi hardware ($150-190 vs $59 Voice PE)
- Routing Discord audio through HA (wrong paradigm)
