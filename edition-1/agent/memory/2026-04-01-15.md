## Session: Puffin Reminder System — Built and Deployed

### What Was Built
1. **Notifier** (family-helper/pkg/schedule/notifier.go, ~230 lines) — Precision timer-based reminder system. Computes exact next reminder fire time across all events (including recurring expansions), sets time.NewTimer(), sleeps until that exact second. On fire: creates one-shot gateway scheduler job. Recalculates instantly on any schedule change via Store.SetOnChange() → Notifier.Recalc().

2. **Client.SendScheduleCreate/Delete** (family-helper/pkg/client/client.go) — Exposes gateway scheduler frame sending for the notifier.

3. **Gateway response routing fix** (gateway/cmd/server/main.go) — Scheduler-originated messages now route via response_channel metadata → Discord channel lookup → FirstChannelID() fallback. Was the invisible wall — "no route for response" log line.

4. **Per-event channel targeting** — NotifyChannel field on Event struct, notify_channel parameter on schedule_add tool. Default empty = use notifier's defaultChannel ("discord-family"). Override: any gateway channel name (e.g. future "macrodroid-bill"). 

5. **Default reminder_minutes = [0]** — fires at event time. Users can customize ("remind me 30 min before" → "30"). "none" disables.

6. **Discord FirstChannelID()** — New method on Discord channel for scheduler-originated messages that don't have a specific discord_channel_id.

### Bugs Found and Fixed
1. **Upcoming() window bug** — Upcoming(1) requires e.When.After(now), so events at their due time vanish from the query. Replaced polling-based notifier with precision timer that computes exact fire times independently.
2. **Gateway no-route** — Response handler only checked discord_channel_id in envelope metadata. Scheduler envelopes have source="scheduler" with response_channel in metadata. Added fallback path.
3. **Hardcoded channel** — Notifier had hardcoded "discord-family". Now reads NotifyChannel from each event with default fallback.

### Key Decisions
- Precision timer over polling — zero CPU between events, zero missed reminders, wakes at exact second
- Per-event channels over global — future-proofs for MacroDroid/phone/SMS channels
- Default reminder_minutes=0 (at event time) not 15 — Bill's explicit request, simpler for "remind me in 2 min"
- Store.SetOnChange callback for recalc — cleaner than threading notifier through tools
