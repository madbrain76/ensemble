### Key Learning: Why Chocolatey OpenCV Failed

**The Problem**: Chocolatey's OpenCV is built with **MSVC toolchain**, not MinGW.
- MinGW linker expects `.a` libraries
- MSVC produces `.lib` libraries
- **Incompatible** - linking fails with "cannot find -lopencv_core4130"

**The Solution**: Build OpenCV from source with MinGW
- gocv provides scripts specifically for this: `win_build_opencv.cmd`
- Takes ~1 hour first time, but caches in CI
- Produces MinGW-compatible libraries in `C:\opencv\build\install\x64\mingw\lib`

Searched for "gocv Windows MinGW OpenCV linking GitHub Actions" and found:
