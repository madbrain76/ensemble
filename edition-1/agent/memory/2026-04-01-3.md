## Handoff Memory — 09:10:41

Built the AI Gateway Phase 1 in one session — 2,435 lines of Go across 12 files, 24 passing tests.

**What was built:**
- Project: ~/projects/gateway/ — pushed to GitHub by Bill
- Noise-KK crypto (pkg/noise/) — adapted from OpenADP's NK. Verified against official spec at noiseexplorer.com/patterns/KK/ and flynn/noise library source. Both parties provide StaticKeypair + PeerStatic, pattern is HandshakeKK. 2-message handshake: msg1 (e, es, ss), msg2 (e, ee, se).
- Config parser (pkg/config/) — JSON config is single source of truth for all routing. Validates agents, channels, scheduler jobs.
- Core types (pkg/types/) — PromptEnvelope, WebSocket frame types, scheduler Job types.
- Router (pkg/router/) — config-driven routing, UUIDv7 message IDs, provenance headers.
- Store (pkg/store/) — JSON file persistence for agent state (queued messages, seq numbers) and dynamic jobs. Save/reload tested.
- Scheduler (pkg/scheduler/) — one goroutine per job, static from config + dynamic creation API, one-shot auto-delete, simple cron parser.
- Agent Manager (pkg/agent/) — WebSocket server with Noise-KK handshake, encrypted JSON frames, at-least-once delivery with seq/ack, provenance headers prepended. Two integration tests: full handshake + message delivery with queuing.
- Main server (cmd/server/) — key gen/load, auto-save 5min, graceful shutdown.

**Key design decisions:**
- Noise-KK (not NK) for mutual authentication — Bill specifically wanted both parties authenticated
- Config file is THE source of truth — no agent self-registration
- Provenance headers: [GATEWAY source=X user=Y trust=Z] prepended to all delivered prompts
- JSON persistence (same pattern as Haven), git-backed
- Handshake protocol over WebSocket: binary msg1 = [1-byte id-len][agent-id][noise-kk-msg1], msg2 = raw noise bytes, then all frames are Noise-encrypted JSON
