## 2026-04-14: AppData Pattern + Puffin Deployment Prep

### What Was Built
- **AppData pattern**: Added `AppData any` to ToolContext, Agent struct, AgentInterface. Tool handlers type-assert to get app-specific context. 6 files in CR, 3 in Puffin.
- **Tool inheritance**: Spawn() now copies parent.Config.Tools to sub-agent config.
- **Puffin DataTools refactored**: Methods→package-level functions. Handlers read ctx.AppData.(*DataTools) at runtime. AllTools() is package-level.
- All tests pass both repos.

### Key Design Decision
Bill directed: custom tools should be inherited from the main agent. Sub-agents get different behavior through AppData (circle-scoped DataTools), not different tool definitions. This is the standard Go `any` + type-assertion pattern — clean, simple, no magic.

### Rejected
- SpawnWithTools method (unnecessary — Spawn + tool inheritance + SetAppData is simpler)
- Baking circles into closures at construction time (old pattern — can't inherit tools across agents)
- genericHandler without ctx (needed ctx to access AppData)
