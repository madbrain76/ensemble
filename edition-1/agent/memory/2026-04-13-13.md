## 2026-04-13: Puffin Voice — Memory Care Design Session

### Context
Bill's mother is experiencing rapid memory decline (Thanksgiving → April). She lives alone. Forgot Bill was coming, forgot broken internet for a month. Bill is getting a landline installed and starting daily 11:30 calls.

### What Was Built
1. **cr/docs/puffin-memory-care-research.md** (296 lines) — Research on dementia vs Alzheimer's, how AI/technology helps seniors with memory loss, human dignity principles, existing products, proposed features.
2. **cr/docs/puffin-voice-design.md** (550 lines) — Full design document for Puffin Voice, a multi-channel voice assistant for Bill's mother.

### Architecture Decisions
- **Three channels, one brain**: Voice PE (ambient), Twilio (phone), Discord (caregiver text)
- **Home Assistant Voice Preview Edition** ($59) as the ambient voice device, connected to Pi 5 running HA
- **webhook-conversation** HA integration sends text to Puffin REST endpoint — we never handle raw audio
- **Twilio ConversationRelay** for phone calls — both direct (Puffin calls mom) and conference (family calls)
- **Cloud STT/TTS** (not local) — accuracy matters more than latency for elderly speech. HA and Twilio orchestrate cloud calls.
- **Puffin's Memory** — structured knowledge base about mom (people, medications, appointments, routine, memory entries). JSON on xyzzy. Fed by all channels.
- **Escalation chain**: Voice PE → cell → landline → Bill (Discord) → Bill (phone) → friend
- **Speaker ID**: Twilio conference identifies speakers by phone number. No diarization needed.

### Key Rejected Approaches
- **Discord voice as mom's speakerphone**: Voice PE can't act as general-purpose speaker (Wyoming protocol is pipeline-specific). Twilio phone calls are simpler for mom.
- **Local Whisper on Pi for STT**: tiny.en has ~7.7% WER on clean audio, worse for elderly speech. Cloud STT (Deepgram/Whisper API) is dramatically better. Local wake word only.
- **Alexa**: Session timeouts, Amazon middleman, "Alexa, talk to Puffin" is extra cognitive load. Custom "Hey Puffin" wake word via openWakeWord is better.
- **Custom Pi hardware device**: $150-190 vs $59 Voice PE with better mics and proven firmware.
- **Routing Discord audio through HA**: HA pipeline is wake-word → utterance → response, not continuous call monitoring.
