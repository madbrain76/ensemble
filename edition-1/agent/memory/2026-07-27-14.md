## 2026-07-27 — cardsense-go: Fixed MTGA Lag by Reducing Frame Capture Rate

**Problem**: Bill reported that MTGA was laggy while CardSense was running, likely due to rapid screen captures.

**Root Cause**: The detector was capturing at 20 FPS (every 50ms), which was unnecessarily frequent for a card detection system where users manually right-click cards. This high capture rate was causing significant CPU/GPU load that interfered with game performance.

**The Fix**: Reduced frame capture rate significantly:
- **Frame rate**: 20 FPS (50ms) → 5 FPS (200ms) = **75% reduction in captures**
- **NO_CARD_FRAMES**: 10 → 5 (still resets after 1 second: 5 frames × 200ms = 1000ms)

**Why This Works**: When a user right-clicks a card in MTGA, the card image stays visible for 1+ seconds. Capturing 5 times per second is more than sufficient to detect it, and the 4× reduction in capture frequency dramatically reduces system load.

**Files Modified**:
- `pkg/detector/detector.go` — Changed FRAME_INTERVAL constant from 50ms to 200ms, NO_CARD_FRAMES from 10 to 5

**Result**: 
- Rebuilt and re-notarized
- Updated cardsense-go.dmg in GitHub release
- Pushed changes to GitHub
- Should eliminate game lag while maintaining full card detection capability

**GitHub Release**: https://github.com/waywardgeek/cardsense-go/releases/tag/v0.3.0

**Lesson**: For user-triggered detection systems (like right-clicking cards), high frame rates are unnecessary. Match the capture rate to the human interaction speed, not to what's technically possible. 5 FPS is plenty for detecting cards that stay visible for 1+ seconds.
