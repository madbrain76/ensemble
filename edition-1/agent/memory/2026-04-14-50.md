## 2026-04-14: Puffin Local Testing Session

### What Was Built
1. **pkg/agent/agent.go fix**: When skills are configured, register ALL default builtin tools plus custom tools (custom takes precedence). Previously only registered defaults when config.Tools was empty, breaking external agents that use both.
2. **puffin/cmd/puffin/main.go fixes**: Added Skill and ProjectPath to AgentConfig, removed separate LoadSkill() call.
3. Updated puffin config.json to new dual-agent format.

### Key Discovery
- Builtin skills ARE embedded in Puffin binary via go:embed (through the coderhapsody/pkg/skills import chain). The issue was that the tool registry didn't have the builtin tools registered when custom tools were provided.
- The fix: when hasSkills is true, always register AllDefaultTools() + config.Tools, with custom tools overriding defaults of the same name.
